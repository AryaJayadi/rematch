## Agent skills

### Issue tracker

Issues live in GitHub Issues on AryaJayadi/rematch, managed with the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Default vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Multi-context: `GLOSSARY-MAP.md` at the root points to one `src/<context>/GLOSSARY.md` per context (booking, play, clubs, competitions, rating, social, coaching, payments, plus the shared kernel), with system-wide ADRs in `docs/adr/`. See `docs/agents/domain.md`.
