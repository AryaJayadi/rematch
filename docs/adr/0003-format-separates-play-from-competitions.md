# A Format is what separates Play from Competitions

A session is an Event (Competitions) when it has a Format that produces Fixtures and Standings: Americano, Mexicano, groups, knockout or a league Season. Anything without one is a Game (Play), however large, even 20 people with randomly picked teams. Coach-led sessions are Lessons (Coaching), whatever their size. Size-based rules were rejected because they split the same activity across contexts depending on headcount.
